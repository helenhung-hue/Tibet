# 冬遊西藏 2026

Trip page for the 9-day Tibet trip (24 Dec 2026 – 3 Jan 2027): countdown, day-by-day itinerary with timings, prep checklist and travel notes.

- Everything lives in `index.html` (no build step).
- Edit trip details in the `DAYS` array inside the `<script>` block; checklist items are in `LIST`.
- Link to a single day with `#day-N`, e.g. `#day-7` for 納木措.
